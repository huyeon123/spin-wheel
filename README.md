# 돌려봐 · Spin Wheel 0.2.8

Windows와 Android를 위한 오프라인 룰렛 게임. Godot 4.6.3 / GDScript / Compatibility 2D 렌더러로 만들었습니다. 서버, 로그인, 광고, 네트워크 권한이 없습니다.

## 사용하기

- 메인 화면은 돌림판, 회전, 결과에 집중합니다. 제목은 시작 화면에서만 나오며 상단 중앙에서 프리셋을 전환합니다. 상단 프리셋 이름을 누르면 미리보기가 있는 관리 화면이 열립니다. 아래에는 넓은 돌리기 버튼과 초기화·룰렛 편집·기록 아이콘이 있습니다. 톱니 아이콘은 전체 설정을 바로 엽니다.
- 연필 아이콘 → `룰렛 편집` 레이어에서 최소 2개의 항목 이름, 색상, 가중치를 직접 편집합니다.
- 비율 모드: 1:1은 각 50%, 1:3은 25%:75%. 새 입력은 양의 정수만 받습니다. 이전 버전에 저장한 소수 값은 정확히 표시하고, 직접 수정하거나 변환하기 전까지 그대로 유지합니다.
- 백분율 모드: 합계 100%가 되어야 회전할 수 있습니다. 편집 중인 미완성 합계도 저장됩니다. 두 라디오 버튼으로 모드를 바꾸면 현재 항목을 자동으로 균등 분배합니다. 비율은 모두1, 백분율은 정수 합계100입니다. 단순히 열거나 저장된 모드를 불러올 때는 값을 바꾸지 않습니다.
- `프리셋 관리`의 `추가`에서 이름을 입력해 룰렛을 추가합니다. 편집은 자동 저장되고, 재실행 시 마지막으로 **돌린** 룰렛이 열립니다.
- 전체 설정의 회전 시간(1–30초), 당첨 항목 제외 여부를 기본으로 사용합니다. `룰렛 편집` 맨 아래의 `이 룰렛 설정`에서 각각 별도로 덮어쓸 수 있습니다.
- 당첨 제외는 현재 라운드에만 적용됩니다. 원본 항목은 남아 있으며 `라운드 복원`으로 돌아옵니다. 1개만 남으면 회전을 중지합니다.
- 결과는 상단 중앙의 프리셋 선택기와 돌림판 사이에 글자만 표시되고 룰렛별 기록에 누적됩니다. 기록 초기화는 확인 후 실행하며 원본 항목에 영향을 주지 않습니다.
- 회전/당첨 효과음은 전체 설정에서 끌 수 있습니다.

## 직접 돌리기

판 바깥쪽을 손가락이나 마우스로 잡고 움직이면 그대로 따라옵니다. 놓으면 같은 방향으로 회전합니다. 중앙의 작은 탭, 너무 짧은 이동, 멈춘 뒤 놓기는 회전을 시작하지 않습니다. Space 키와 넓은 돌리기 버튼도 사용할 수 있습니다. 회전 시간 설정은 손을 놓은 뒤의 애니메이션 길이에 적용합니다. 결과는 가중치로 공정하게 선택되므로 손동작으로 특정 항목을 강제로 선택할 수 없습니다.

설정된 시간과 확률 결과에 맞추는 게임 애니메이션이며 실제 마찰 시뮬레이션은 아닙니다. 손을 놓을 때 위치와 속도는 연속이지만, 느린 제스처와 짧은 회전 시간 조합에서는 목표까지 부드럽게 가속할 수 있습니다.

## 공정성 및 동작

가중치로 당첨 항목을 회전 시작 시 **한 번만** 선택합니다. 실제 부채꼴 각도와 선택 확률은 같은 가중치를 사용합니다. 포인터는 해당 부채꼴 중앙에 착지합니다. 손가락/마우스 드래그 방향과 속도를 이어받아 quintic 경로로 착지하며, 회전 중 편집과 중복 실행은 차단합니다. 앱을 회전 중 종료하면 완료되지 않은 회전은 기록하지 않습니다.

당첨 제외 후에는 결과를 확인할 수 있도록 착지한 판을 잠시 유지하며, 다음 회전에서 남은 항목으로 판을 갱신합니다. 항목의 값 편집은 현재 라운드를 복원합니다. 순서만 변경할 때는 제외된 항목과 기록을 유지합니다.

편집기는 메인 화면에 배치하지 않습니다. 작은 화면에서도 레이어 안을 스크롤해 모든 항목에 접근할 수 있습니다. 닫기/Escape/Android 뒤로 가기는 열린 레이어부터 닫습니다. 변경은 즉시 자동 저장되며 닫기를 취소/되돌리기로 오해하지 않도록 레이어에 안내합니다. 회전 중에는 설정과 편집을 열 수 없습니다.

## 저장과 개인정보

`user://state.json`에 로컬로만 저장합니다. 검증된 임시 파일을 만든 뒤 교체하고 직전 저장의 `.bak`을 유지합니다. 손상 파일은 `.corrupt-*`로 보존하고 유효한 백업을 복구합니다. 복구가 불가능하면 기본 룰렛으로 시작합니다. 기록은 자동으로 잘라내지 않습니다. 앱 제거/기기 데이터 삭제 시 로컬 기록도 사라질 수 있습니다.

## 실행 / 테스트 / 빌드

Godot 4.6.3에서 `project.godot`을 열어 실행합니다. 외부 패키지가 필요하지 않습니다.

```sh
godot --headless --path . --editor --import
godot --headless --path . --script tests/test_model.gd
godot --headless --path . --script tests/test_ui.gd
godot --headless --path . --script tests/test_overlays.gd
godot --headless --path . --script tests/test_gestures.gd
godot --headless --path . --script tests/test_fixed_layers.gd
godot --headless --path . -- --smoke
```

UI 테스트는 별도 사용자 데이터 경로에서 실행하세요. 테스트가 저장 데이터를 만듭니다. CI는 임시 XDG_DATA_HOME을 사용합니다.

Windows / Android export와 GitHub Actions는 [빌드 안내](docs/BUILD.md)를 참고하세요. APK는 개발용 debug 서명입니다. Google Play 출시용 서명/AAB, Windows 코드 서명, 실제 기기 성능 검증은 별도 단계입니다. iOS 코드는 이식 가능한 구조지만 Xcode/macOS에서의 서명·빌드·실기기 검증은 아직 수행하지 않았습니다.

## 가벼운 실행을 위한 선택

브라우저 런타임이나 서버 없이 하나의 2D CanvasItem을 회전합니다. 부채꼴과 글자 그리기는 항목/크기가 바뀔 때만 갱신하며 회전 중에는 캐시된 판의 transform만 변경합니다. 60 FPS 상한, 비회전 시 low-processor-usage 모드를 사용합니다. 효과음 두 개는 합계 약 55KB, 한국어 폰트는 약 2MB입니다. 배포 크기는 기본 Godot 엔진을 포함하므로 아주 작지는 않습니다. 저사양 기기의 실측 성능이나 최소 메모리 사용량을 보장하지 않습니다.

스타일은 연한 색조 배경, 여백, 떠 있는 컨트롤, 최소한의 글자에 집중합니다. 스크롤바는 숨기되 터치 스크롤과 마우스 휠은 유지합니다. 모션 참고: [Material motion](https://m3.material.io/styles/motion/overview/how-it-works), [Fluent motion](https://fluent2.microsoft.design/motion).

설정·편집·기록·선택·색상 레이어는 앱 안의 고정 Control 오버레이입니다. 창처럼 드래그하거나 크기를 바꾸지 않으며, 화면 크기에 맞게 배치됩니다. 내부는 마우스 휠/터치로 스크롤하고, Escape·뒤로 가기·오른쪽 위 닫기로 닫습니다.

## 프리셋과 순서 관리

프리셋별 작은 돌림판 미리보기에서 선택·룰렛 편집·삭제를 할 수 있습니다. 노란 별은 즐겨찾기이며 자동 정렬하지 않습니다. 프리셋과 항목 왼쪽 손잡이를 끌어 직접 순서를 바꿀 수 있고, 가장자리에서는 자동 스크롤합니다. 키보드는 손잡이에 초점을 두고 Alt+위/아래를 사용합니다. Escape/뒤로 가기는 진행 중인 드래그부터 취소합니다. 순서와 즐겨찾기는 재실행 후에도 유지됩니다. 룰렛 이름 수정은 같은 프리셋의 이름만 바꾸며 ID·기록·설정은 유지합니다.

0.2.1에서는 드래그 중 미리보기가 손잡이를 잡은 위치를 연속적으로 따라가며, 삽입 표시선과 독립적으로 움직입니다. 삭제 버튼은 모든 상태에서 같은 여백과44px 영역을 유지합니다. 결과 기록은 당첨 이름과 시간을 구분하고, 저장된 색상이 있는 기록에만 색을 표시합니다.

0.2.2는 선택한 라디오 버튼에 마우스를 올렸을 때 글자와 배경이 사라지던 상태 테마 누락을 수정합니다. 선택·호버·누름·초점·비활성 상태의 색을 명시하고 실제 렌더링 회귀 검사를 추가했습니다.

Windows/macOS/Linux에서는 시작 시 현재 모니터의 사용 가능한 영역에 맞춘 세로 창으로 열립니다. 작업 표시줄·창 장식·화면 배율을 고려해 크기를 제한하며, 실행 후에는 자유롭게 창 크기를 바꿀 수 있습니다. Android 화면 방향과 로컬 저장 데이터는 바꾸지 않습니다.

0.2.4에서는 모든 레이어의 오른쪽 위 닫기 아이콘을 빨간색으로 통일하고, 호버·누름·초점·비활성 상태에서도 아이콘 크기와 중심, 클릭 영역이 바뀌지 않도록 고정했습니다.

회전판 아래 그림자는 별도의 고정 레이어로 그려져 회전 중에도 화면 아래쪽에 머무릅니다. 창 크기를 바꾸면 회전판의 중심과 크기를 따라갑니다.

0.2.5는 초기 실패한 가져오기 과정에서 남은 내보내기 캐시 때문에 Android 메인 화면 스크립트가 누락되던 배포 문제를 수정합니다. 빌드는 매번 격리된 새 작업 폴더에서 실행하고, Windows 내장 리소스와 APK에서 실제 메인 스크립트·UI 초기화를 검증한 뒤에만 산출물을 배포합니다.

### 0.2.6
Android 화면의 카메라·시스템 안전 영역을 반영하고, 룰렛을 중앙에 배치하며 회전 버튼과 보조 버튼을 하단에 둡니다. 회전 시간은 1–30초의 일반 숫자(소수 포함)만 입력합니다. 새 룰렛은 이름이 빈 항목 2개와 1:1 비율로 시작하며, 기존 저장 내용은 바꾸지 않습니다. 항목 글자는 기본 2px 커지고 긴 이름은 공간에 맞게 줄여 표시합니다.

### 0.2.7 테스트 후보
상단 당첨 결과를32px, 최대 두 줄로 확대합니다. 룰렛 편집을 열 때 입력칸에 자동 포커스하지 않아 직접 누르기 전에는 키보드를 요청하지 않습니다. Android 테스트 APK에는 공식4.6.3 소스로 빌드한 경량2D 엔진을 포함합니다. 새 엔진의 실제 기기 동작과 설치 용량은 별도 확인이 필요합니다. 일반 CI 산출물은 공식 엔진이며, 경량 테스트 APK는 Release 설명에 명시된 파일입니다.

### 0.2.8 음향 테스트 후보
회전 각도 이동에 맞춘 짧은 래칫 클릭과 직접 합성한1.24초 팡파르를 사용합니다. 클릭은 회전당24개 가상 톱니를 기준으로 감속에 따라 늦어지며, 최대 초당25회로 제한하고 밀린 소리를 몰아 재생하지 않습니다. 음소거와 앱 비활성화는 즉시 소리를 멈춥니다. 배경으로 전환된 회전의 소리는 돌아와도 뒤늦게 재생하지 않으며 다음 회전부터 다시 활성화됩니다.

정지 위치는 먼저 가중치대로 선택한 당첨 칸 안에서 독립적인 균등 난수로 결정합니다. 칸 중앙에 고정하지 않으며, 수치 경계 오판 방지를 위한 최대1e-10라디안 여유 외에 전체 구간을 사용합니다.
